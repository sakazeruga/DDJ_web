# Deep Dive Japan (DDJ) 🗾⚡
> **「日本を、もっと深く沼れ。」**  
> 一般の観光ガイドブックでは絶対に出会えない、ローカルオタクが案内する至高のディープツアー投稿＆発見プラットフォーム

---

## 🌟 プロジェクト概要
**Deep Dive Japan** は、訪日インバウンド旅行者や国内のサブカルチャーファンに向けて、日本のディープなオタクカルチャー体験を提供する特化型ツアーマーケットプレイスです。

秋葉原の電子部品ジャンク街、中野ブロードウェイのヴィンテージセル画＆トイ魔境、アニメの聖地巡礼（『ぼっち・ざ・ろっく！』『ラブライブ!サンシャイン!!』等）、レトロアーケード基板探索など、一般の旅行会社では企画不可能な超コアな体験を、圧倒的な熱量を持つオタクガイドが案内・投稿できます。

---

## ✨ 主な機能

### 1. 🔍 オタクツアー探索・高度な絞り込み
- **ジャンル別検索**: 聖地巡礼 / 秋葉原裏ルート / 中野ブロードウェイ / レトロゲーム＆基板 / 池袋乙女ロード / メイド＆コンカフェ / 同人誌即売会
- **オタク度レベル（Lv.1〜Lv.5）**: ビギナー歓迎から「超限界オタク・沼」まで明示
- **エリア・価格・所要時間・対応言語** での複合フィルタリング
- **ソート機能**: 人気順、オタク度順、新着順、価格順

### 2. 🗺️ ツアー詳細 & タイムライン行程表
- **タイムライン行程**: 時間別のスポット詳細と、必見の「超ディープスポット」バッジ
- **ガイド情報**: オタク歴、専門ジャンル、推しへの熱量
- **事前準備・持ち物**: 履修推奨アニメや作品（例:「1期〜8話まで履修推奨」）、100円玉やエコバッグなどの持ち物
- **リアルタイム予約シミュレーター**: 日付、人数、推しへの熱量メッセージを入力してワンクリック予約（紙吹雪演出付き）
- **参加者レビュー投稿**: 星評価とコメント投稿

### 3. ✍️ オタクツアー投稿機能（Tour Creator Studio）
- 誰でもガイドとして自分の聖地や得意ジャンルのツアーを企画・投稿可能
- 動的タイムライン行程エディタ（スポット追加・削除、ディープスポット指定）
- 投稿したツアーはLocalStorageに即時永続化され、一覧・マイページにリアルタイム反映

### 4. 📢 「連れてって！」リクエスト掲示板（Request Board）
- 行きたい作品やスポットのリクエストを旅行者が投稿
- 「私も行きたい！（+1）」の共感・投票機能
- ガイドからの提案受付

### 5. 👤 マイページ & ダッシュボード（My Page）
- **予約したツアー**: 参加日程、人数、合計金額、キャンセル機能
- **お気に入り（ブックマーク）**: ワンクリックで保存したツアーの一元管理
- **自分が投稿したツアー**: 作成したツアーの管理・削除

### 6. 🌐 日英バイリンガル対応（JP / EN）
- 画面右上の言語トグルで、日本語と英語を瞬時に切り替え可能

## 🛠️ 技術スタック
- **Frontend Framework**: React 19 + TypeScript
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4（サイバーパンク × 和風ネオンデザイン）
- **Icons**: Lucide React
- **Animations / Effects**: Canvas Confetti
- **State & Storage**: React State + Browser LocalStorage

---

## 🚀 起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# プロダクションビルド
npm run build
```

開発サーバー起動後、ブラウザで `http://localhost:5173` にアクセスしてください。
